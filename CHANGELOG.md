## 1.0.0 — 2026-10-11

### Release notes

SeekDash 1.0.0 is the first public Windows release of the local-first launcher.

- Indexed application, shortcut, file, and folder search with usage-aware ranking.
- Horizontal launcher and expandable edge sidebar.
- Native application icons, favorites, and context actions.
- Opt-in text Clipboard History with optional local persistence.
- Quick Actions command palette with guarded Windows power actions.
- Settings for appearance, layout, indexing, shortcuts, favorites, and clipboard behavior.
- English, Turkish, German, and French interfaces.
- Per-user, four-language NSIS installer for Windows x64.
