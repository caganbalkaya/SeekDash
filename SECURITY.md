# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not disclose security vulnerabilities in a public issue.

Use [GitHub Private Vulnerability Reporting](https://github.com/caganbalkaya/SeekDash/security/advisories/new) if it is enabled. Otherwise, contact the project through [seekdash.com.tr](https://seekdash.com.tr) and request a private reporting channel. Include the affected version, impact, reproduction steps, and any proof of concept. Do not include real clipboard content, credentials, or unrelated personal data.

Receipt and remediation timelines will be communicated through the private reporting channel. No security bounty program is currently offered.
